# 🧩 Cuber Hub

Welcome to **Cuber Hub** — a website made for Rubik's Cube enthusiasts and speedcubers.

## 🌐 Website

Visit the website:
https://a4ashishh.github.io/cuber-hub-website/

## ✨ Features

- 🧩 Rubik's Cube learning resources
- ⏱️ Cube timer
- 📚 Algorithms and solving guides
- 🏆 Speedcubing practice
- 📱 Mobile-friendly design
- 🎨 Simple and user-friendly interface

## 🎯 Purpose

Cuber Hub is designed to provide cubers with useful tools and resources in one place, whether they are beginners or experienced speedcubers.
